# trogenne-bot-builderv2
Türkçe,
    Bu bot istediğiniz türde istediğiniz komutları belirleyerek kısa süre içinde size botun ana dosyasını atar ve kuruluma kadar yardım eder. Kurulum için tek lazım olan şey Python 3.10 sürümünün üstü olmasıdır. İyi kullanmalar!

English,
     By allowing you to specify the type of bot and the commands you want, this bot quickly provides you with the main bot file and assists you through the installation process. The only requirement for installation is having Python version 3.10 or higher. Enjoy using it!

French,
     En vous permettant de spécifier le type de bot et les commandes souhaitées, cet outil génère rapidement le fichier principal du bot et vous guide tout au long du processus d'installation. La seule condition requise pour l'installation est de disposer de Python version 3.10 ou supérieure. Profitez-en bien !

Deutsch,
      Nachdem du die gewünschten Befehle und den Bot-Typ festgelegt hast, sendet dir dieser Bot innerhalb kurzer Zeit die Hauptdatei zu und unterstützt dich bei der Einrichtung. Für die Installation ist lediglich Python 3.10 oder eine neuere Version erforderlich. Viel Spaß bei der Nutzung!
